## Document Guidelines:

### CV/Resume:
- **Format**: PDF (universally compatible)
- **Length**: 2-4 pages for academic CV, 1-2 pages for industry resume
- **Font**: Professional fonts (Times New Roman, Arial, Calibri)
- **Sections**: Contact, Education, Experience, Publications, Skills, Awards
- **Naming**: Use clear, professional naming convention

### Research Papers:
- **Format**: PDF
- **Quality**: High resolution, readable text
- **Metadata**: Include proper title, authors, publication info
- **Size**: Optimize for web (aim for <5MB per paper)

### Best Practices:
- Keep all documents up-to-date
- Use consistent formatting across documents
- Include publication dates and version numbers
- Ensure all links and contact information are current
- Test download links regularly

## Privacy Considerations:
- Remove or redact sensitive personal information if needed
- Consider creating a public version of your CV with minimal personal details
- Ensure compliance with any publication or confidentiality agreements
